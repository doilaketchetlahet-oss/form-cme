## Reproduce

Install `playwright-core` and `@axe-core/playwright` into a separate temporary directory and set `HOME_UI_DEPS` to it. Start `npm run start -- --hostname 127.0.0.1 --port 3115` after building, then run `node scripts/test-home-ui.cjs`. `HOME_UI_BASE` and `HOME_UI_OUTPUT` override the server and screenshot folder; `PLAYWRIGHT_CHANNEL=msedge` selects Edge instead of Chrome.

Limits: mobile runs use browser viewport emulation, not a physical iPhone/Android device. Supplied artwork and local demo states were tested. No real account registration, mail sending, check-in, database operation or storage upload was performed.
